# What is the .NET Framework?
-> The .NET Framework is a software development framework developed by Microsoft. It provides a runtime environment called CLR and a class library called FCL. It supports application development using languages such as C# and VB.NET. It also provides features such as memory management, garbage collection, and exception handling.

CLR:The CLR is the execution engine of the .NET Framework.
FCL:The FCL is a collection of reusable classes, interfaces, and other types that help developers perform common tasks.

# What is Intermediate Language (IL) in .NET?
->Intermediate Language, or IL, is the intermediate code generated by the C# compiler. It is stored in a .NET assembly. At runtime, the JIT compiler converts IL into native machine code that the CPU can execute. IL also allows different .NET programming languages to use a common execution environment.

# What is an assembly in .NET, and what is its structure?
->An assembly is a compiled unit of a .NET application, typically stored in a .dll or .exe file. It contains Intermediate Language (IL), metadata, and an assembly manifest. It can also contain embedded resources. The manifest identifies the assembly and describes its dependencies and other assembly information.

# What is an EXE file?
->An EXE file is an executable file that can launch an application. It can contain compiled code and an application entry point.

# What is a DLL file?
->A DLL is a Dynamic Link Library that contains compiled code and provides reusable functionality to applications or other assemblies.

# What is CLR, and what are its functions?
->CLR stands for Common Language Runtime. It is the execution engine of the .NET Framework that manages the execution of managed code. Its main functions include JIT compilation, memory management, garbage collection, exception handling, type safety, security services, and support for multithreading and interoperability.

# What is JIT compilation in .NET?
->JIT stands for Just-In-Time. It is a compiler used by the .NET runtime to convert Intermediate Language into native machine code at runtime. This machine code can then be executed by the CPU. JIT compilation also allows the runtime to optimize code during compilation.

# What is memory management in .NET?
-> Memory management in .NET is the process of allocating and managing memory for an application. The CLR provides automatic memory management through garbage collection, which reclaims memory occupied by unreachable managed objects.

# What is Garbage Collection in .NET?
->Garbage Collection is the automatic process of reclaiming memory occupied by managed objects that are no longer reachable. It is managed by the .NET runtime.

#  What are the three generations of Garbage Collection?
->Generation 0, Generation 1, and Generation 2. They help the GC manage objects based on how long they survive across collections.

# Can we force Garbage Collection?
->We can request a collection using GC.Collect(), but it is generally recommended to let the runtime manage garbage collection automatically.

# Does Garbage Collection call Dispose() automatically for every object?
->No. Garbage collection does not guarantee that Dispose() will be called for every object. Developers should explicitly dispose of resources when required, commonly by using a using statement.

# What is AppDomain Management in .NET?
->AppDomain management in the .NET Framework refers to creating, configuring, and unloading application domains. An AppDomain provides an isolated environment for managed code within a process. It allows assemblies to be loaded into a domain and unloaded by unloading the entire domain. In modern .NET, additional AppDomains are not supported in the same way, and AssemblyLoadContext is used for certain assembly-loading and unloading scenarios.

# What is ILDASM in .NET?
->ILDASM stands for Intermediate Language Disassembler. It is a Microsoft tool used to inspect .NET assemblies, such as EXE and DLL files. It allows developers to examine IL instructions, metadata, classes, methods, and assembly information.

# What is a Console Application in C#?
->A Console Application is a program that interacts with users through a text-based interface. It uses the Console class to accept input and display output.

# What is a Class Library in .NET?
->A class library is a reusable collection of classes, methods, interfaces, and other types. It is commonly compiled into a DLL that can be referenced by other .NET applications.

# Why do we use Class Libraries?
->We use class libraries to reuse code, separate responsibilities, improve maintainability, and organize large applications into modules.

# What is the using keyword in C#?
->In C#, using is used in different contexts. The using directive allows us to access types from a namespace without specifying their fully qualified names. The using statement helps manage disposable resources by ensuring that Dispose() is called when execution leaves the scope.

# What is an interface in C#?

An interface defines a contract that implementing classes must follow. It declares members such as methods and properties, which a class implements. C# allows a class to implement multiple interfaces, supporting flexibility and abstraction.

# Interface members have specific accessibility rules
Traditional interface members such as abstract method declarations are implicitly public. Modern C# supports other access modifiers for certain interface members, including private helper methods and default implementations.

# What Is Explicit Interface Implementation?
Explicit interface implementation means implementing an interface member using the interface name along with the member name.

It is useful when:
- A class implements multiple interfaces that contain methods with the same name.
- You want an interface member to be accessible only through an interface reference, rather than directly through the class object.

{

        // d.Sound(); // Compilation error

The ?? operator returns the left-hand value if it is not null; otherwise, it returns the right-hand value. The ??= operator assigns the right-hand value to the left-hand variable only when the variable is null.

# What is a delegate in C#?
->A delegate is a type-safe reference to a method. It allows us to assign compatible methods to a delegate variable and invoke them through that variable. Delegates support callbacks, event handling, and multicast operations.

# Why Do We Use Delegates?
->Delegates are useful for:
1. Passing methods as arguments to other methods.
2. Implementing callback functionality.
3. Invoking multiple methods through multicast delegates.
4. Supporting event handling in C#.
5. Making code more flexible and reusable.

# How can you call a method using a delegate in C#?

First, we declare a delegate with a compatible signature. Then, we assign a method to the delegate and invoke it using the delegate variable. Delegates allow us to call methods indirectly and are useful for callbacks and event handling.

# What is a Multicast Delegate?
A multicast delegate is a delegate that can reference multiple methods and invoke them through a single delegate call.

# What is a multicast delegate in C#?

A multicast delegate is a delegate that can reference multiple methods with compatible signatures. We use += to add methods and -= to remove them. When invoked, it executes its methods in invocation-list order. If the methods return values, the invocation returns the value from the last method executed.

# Action Delegate
Definition: Action is a built-in delegate used to refer to a method that returns no value (void).

# Func Delegate
Definition: Func is a built-in delegate used to refer to a method that returns a value.

# Predicate Delegate
Definition: Predicate<T> is a built-in delegate that accepts one parameter of type T and returns a bool (true or false).

# What is an Anonymous Method?
An anonymous method is a method without a name. We can define it directly where a delegate is assigned, instead of creating a separate named method.

# What is an anonymous method in C#?

An anonymous method is a method without a name that is defined inline using the delegate keyword. It can be assigned to a compatible delegate and can accept parameters and return values. It is useful when we need to define a small method without creating a separate named method.
